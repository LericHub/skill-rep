# Skill Repository

This repository contains a collection of OpenClaw skills.

## Skills

### llm-wiki-ingest
A skill for ingesting wiki content using LLM.

### content-archiver
A tool for extracting and archiving web content to Feishu documents.

### prd-assistant
An assistant for writing structured Product Requirement Documents (PRD).

### news-aggregator-skill
A comprehensive news aggregation skill covering 28+ sources including Hacker News, GitHub Trending, HuggingFace Papers, Wall Street CN, Weibo Hot Search, and more.

### harness-news-skill
A skill for fetching news from Harness platform.

### tc-deeptrip
A skill for deep trip queries.

## Usage

Each skill is organized in its own directory with a `SKILL.md` file that contains the skill's metadata and instructions.

To use a skill, copy it to your OpenClaw workspace and ensure it follows the OpenClaw skill specification.

## Contributing

To add a new skill:
1. Create a new directory for your skill
2. Add a `SKILL.md` file with the skill's metadata
3. Include any necessary scripts, references, or documentation
4. Submit a pull request
