# LLM Wiki 新结构规范

## 架构概览

```
llm-wiki/
├── wiki/
│   ├── topics/           # 主题聚合页 (按查询场景组织)
│   │   ├── Agent 架构体系.md
│   │   ├── 可观测性与追踪.md
│   │   └── 前后端协作规范.md
│   ├── entities/         # 实体百科 (原子化定义)
│   │   ├── DeepAgents.md
│   │   ├── LangChain.md
│   │   ├── LangSmith.md
│   │   ├── Main Agent.md
│   │   ├── Sub Agent.md
│   │   ├── 事件流.md
│   │   ├── 星形架构.md
│   │   └── 全链路追踪.md
│   ├── archive/          # 归档文档 (原始摄取内容)
│   │   ├── 动态星形多Agent架构部署方案.md
│   │   ├── DeepAgents Stream状态流及前后端对接.md
│   │   └── MeowBot 接入 LangSmith.md
│   └── system/           # 系统页面
│       ├── index.md      # 完整索引
│       └── log.md        # 操作日志
└── raw/                  # 下载的原始文件
```

## 页面类型说明

### 1. 主题聚合页 (Topics)

**目的**: 按"查询场景"组织内容，减少LLM跨页查询

**内容结构**:
- 核心概念摘要 (200-300字)
- 关键实体表格
- 知识点 (按时间倒序)
- 来源文档列表
- 快速查询FAQ

**更新时机**: 每次摄取新文档后

### 2. 实体百科页 (Entities)

**目的**: 原子化的实体定义，供主题页引用

**内容结构**:
- 实体类型和定义
- 描述详情
- 相关主题链接
- 来源文档引用
- 相关实体链接

**更新时机**: 
- 新实体首次出现时创建
- 现有实体被新文档提及时更新"来源"和"相关主题"

### 3. 归档文档页 (Archive)

**目的**: 保留原始文档完整内容，供追溯

**内容结构**:
- 元数据 (时间、来源、类型、主题)
- 核心摘要
- 生成的实体列表
- 知识点
- 完整内容

**更新时机**: 每次摄取时创建，之后只读

### 4. 系统页 (System)

**目的**: 维护和索引

**index.md**:
- 主题清单
- 实体清单
- 归档文档清单
- 实体-主题映射表

**log.md**:
- 摄取操作记录
- 主题变更记录
- 实体变更记录

## 主题分类规则

### Agent 架构体系

**匹配关键词**:
- 星形架构, 多Agent, Agent协作
- Main Agent, Sub Agent
- 调度, 任务分发, 负载均衡
- LangGraph, 状态机
- 中心节点, 子节点

**典型文档**:
- 架构设计方案
- Agent角色定义
- 调度策略文档

### 可观测性与追踪

**匹配关键词**:
- LangSmith, 可观测性
- 追踪, Tracing, 监控
- ProjectID, TraceID, RunID
- 全链路, 链路追踪
- 性能监控, 调试

**典型文档**:
- LangSmith接入方案
- 追踪ID设计规范
- 监控告警配置

### 前后端协作规范

**匹配关键词**:
- Stream, 事件流
- 前后端, Frontend, Backend
- SSE, WebSocket
- 状态流, astream_events
- 协作规范, 接口协议

**典型文档**:
- 前后端接口规范
- 事件流设计
- 状态管理方案

## 摄取工作流程

```
1. 下载文档 → raw/
2. 主题分析 → 确定 primary/secondary topics
3. 实体提取 → 识别 mentioned entities
4. 更新主题页 → 追加新内容
5. 更新实体页 → 添加来源和主题链接
6. 创建归档页 → 保存完整内容
7. 更新系统索引 → 更新统计和映射
8. 移动源文档 → 已归档文件夹
```

## 链接规范

**内部链接格式**:
- 主题页: `[[主题聚合/主题名]]`
- 实体页: `[[实体百科/实体名]]`
- 归档页: `[[归档文档/文档名]]`
- 系统页: `[[系统/页面名]]`

**双向链接原则**:
- 主题页 → 实体页 (在"关键实体"表格中)
- 实体页 → 主题页 (在"相关主题"部分)
- 归档页 → 主题页 + 实体页
- 系统索引 → 所有页面

## 大小控制

| 页面类型 | 建议大小 | 超限处理 |
|----------|----------|----------|
| 主题页 | < 5000字 | 拆分为主题+子主题 |
| 实体页 | < 3000字 | 拆分为核心+扩展 |
| 归档页 | 无限制 | 完整保留 |
| 系统索引 | < 5000字 | 分页或精简 |

## 命名规范

**文件名**:
- 使用中文名称
- 保留原始文档标题 (归档页)
- 实体名与文中引用一致

**页面标题**:
- 主题页: 简短描述性名称
- 实体页: 实体名本身
- 归档页: 原始文档完整标题
